# 17 - Testing & Quality Assurance

## 🧪 Strategi Testing & Quality Control

- **Linting**: Run `npm run lint` untuk mengecek kesalahan sintaksis dan isu tipe TypeScript.
- **Production Build Test**: Run `npm run build` untuk memverifikasi bahwa bundling Vite dan esbuild berjalan lancar tanpa error.
- **Manual Feature Verification**: Pengujian aliran data transaksi, AI Investment Advisor, dan OCR struk belanja.
