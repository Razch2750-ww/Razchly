# 09 - Feature: Authentication & Firebase User Management

## 🔐 Modul Otentikasi & Firebase Auth

Modul pengelolaan sesi pengguna dan sinkronisasi cloud terenkripsi.

### Fitur Utama:
- **Firebase Auth**: Login berbasis Email/Password atau Google Sign-In.
- **Sesi Persistent**: Sesi bertahan di browser menggunakan `onAuthStateChanged`.
- **Mode Tamu / Local Storage**: Aplikasi tetap dapat digunakan secara lokal saat offline atau sebelum login.
