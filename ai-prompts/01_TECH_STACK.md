# 01 - Tech Stack

## 🛠️ Stack Utama Aplikasi

### Frontend
- **Framework**: React 19 dengan TypeScript
- **Build Tool**: Vite
- **Styling**: Tailwind CSS (Utility-First)
- **Animasi**: Motion (`motion/react`)
- **Ikon**: Lucide React (`lucide-react`)
- **Grafik & Data Visualization**: Recharts, D3

### Backend & API Proxy
- **Runtime**: Node.js & Express.js (`server.ts`)
- **Bundler**: esbuild (Membundle backend ke Single CommonJS `dist/server.cjs`)
- **Dev Runner**: `tsx`

### Database & Cloud Services
- **Cloud Database**: Firebase Firestore
- **Authentication**: Firebase Auth
- **AI Model SDK**: `@google/genai` (Gemini 3.6 Flash)
